# NewsExplorer: Front End

The front-end project is focused on creating a user interface for the news explorer application. It includes working with creating the layout, implementing authorisation and authentication based on jwt token, searching the news based on keywords, rendering the news articles as cards, saving news articles to the user profile, deleting the cards. The goal is to create a web app with the rest API and user authorization.

## Project features

- Implement the logic for signing up, signing in, and signing out
- Provision to search news article for any user
- Implement the logic for saving and deleting the news cards for the user profile
- Implement the responsive user interface so users can access from desktop, tablet and mobile phones

## Technologies and Techniques

- React
- Html 5
- CSS 3
- Javascript
- Semantic HTML5
- Flexbox
- Positioning
- Flat BEM file structure
